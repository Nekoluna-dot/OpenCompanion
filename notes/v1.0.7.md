# v1.0.7 修复记录

> 本文件记录 v1.0.7 版本修复的功能与缺陷，按时间倒序排列。

---

## 修复一：首次启动不会自动加载默认预设（必须手动点"激活"才可用）

- **现象**：全新部署后直接启动，机器人没有可用的人设——必须先进网页控制台
  「人设预设」页手动点一次**激活**，根目录才会生成 `prompt.txt` /
  `prompt_extra.txt`，机器人才正常。否则读不到系统提示词。
- **根因**：
  - 预设机制的设计是「**根目录的 `prompt.txt` / `prompt_extra.txt` 才是当前生效文件**」，
    预设目录（`prompts/<名>/`）只是模板，点「激活」时才把模板**复制到根目录**覆盖。
  - `PromptsManager._ensure_layout()` 在首次创建 `default/` 预设时，只是把根目录的
    `prompt.txt` / `prompt_extra.txt` **复制进** `prompts/default/`，**不会回写根目录**。
  - 因此当根目录的这两个文件缺失时（全新部署 / Docker 挂载了空的 `prompt.txt`），
    `AppConfig._load_prompt()` 直接 `FileNotFoundError`，人设始终是空的，
    必须手动激活一次才会补齐。
- **修复**（均只在**根目录文件缺失**时才从激活预设补写，绝不覆盖已有文件）：
  - `botapp/webconsole/prompts.py` 新增 `PromptsManager.ensure_initial_active()`：
    读取 `prompts/.active` 指向的预设，把其中存在、而根目录缺失的
    `prompt.txt` / `prompt_extra.txt` 补写到根目录。
  - `botapp/webconsole/server.py` 新增 `_ensure_prompts_active()`，在 `start()`
    里（拉起机器人之前）调用；补写时打印一行日志。
  - `botapp/config.py` 增加兜底 `_preset_file_fallback()`：即使绕过网页控制台
    直接跑 `main.py`，根目录缺文件时也能从激活预设（缺失则回退 `prompts/default/`）
    读取，不再直接报错。新增 `_resolve_prompt_path()` / `_resolve_prompt_extra_path()`，
    `reload_prompt()` / `reload_prompt_extra()` 也改为按解析后的路径判重，
    使热加载在"根目录缺失、走预设"时同样生效。
- **验证**：
  - 单元：模拟全新部署（根目录缺 prompt、预设有）→ 自动补写；
    根目录已有文件 → 不被覆盖（只补缺失项）；激活指向不存在的预设 → 安全返回。
  - `AppConfig` 五场景：根目录缺→用预设、根目录全→用根目录、两者皆缺→报错、
    激活指向 ghost→回退 default、只缺 extra→兜底 extra；`reload_prompt_extra`
    能感知预设文件变化。真实仓库 `AppConfig()` 仍正确加载根目录 prompt（3055 字符）。
  - 无头浏览器：`#/prompts` 正常渲染，`default` 预设显示为「当前」。

## 修复二：请求不存在的预设导致后端抛异常刷堆栈

- **现象**：控制台日志出现
  `FileNotFoundError: 预设不存在: 532` 的完整堆栈
  （`do_GET` → `prompts.read_preset`）。
- **根因**：`do_GET` 的 `/api/prompts/<name>` 分支直接调用
  `read_preset()`，而它在预设不存在时抛 `FileNotFoundError`；该分支未被
  `try/except` 包裹，异常冒泡到 `BaseHTTPRequestHandler`，由标准库打印堆栈。
  （前端 `loadPreset()` 在「刷新列表」与「新建后加载」之间存在竞态/无效名，
  会请求到不存在的预设名，例如被解析成的 `532`。）
- **修复**：
  - `botapp/webconsole/server.py`：该分支用 `try/except (FileNotFoundError,
    ValueError)` 捕获，返回 `404 {"error": "预设不存在: xxx"}`，不再抛异常。
  - `botapp/webconsole/webui/src/pages/Prompts.vue`：`loadPreset()` 读取失败时
    静默清空编辑器，不再弹红色错误 toast（预设可能刚被删除/改名）。
- **验证**：真实 `WebConsoleServer` 上 `GET /api/prompts/532` → `404`
  且 body 为 `{"error": "预设不存在: 532"}`；`GET /api/prompts/default` → `200`。
