# v1.0.10 修复记录

> 本文件记录 v1.0.10 版本修复的功能与缺陷，按时间倒序排列。

---

## 移除 7 个外部 MCP 工具源（movie / emoji / location / topic / weather / tts / bili）

- **现象**：用户希望精简项目，删除以下外部 MCP 工具源及其配置：
  `movie`（电影票房）、`emoji`（表情列表）、`location`（IP 定位）、
  `topic`（话题兴趣）、`weather`（天气）、`tts`（语音合成）、`bili`（B站检索）。
- **根因**：这些工具源属于可选的第三方接入，随项目一起分发会让仓库显得臃肿、
  依赖变多，且默认示例配置里仍保留着它们的条目，容易误导用户以为必须启用。
- **修复**：
  - **配置**（`config.ini` 的 `[mcpsources]`）：删除 `movie / emoji / location / topic /
    weather / bili / tts` 共 7 条示例条目，以及 `# B站（免登录）…`、`# TTS 语音服务…`
    两行说明注释。保留 `ombre`（长期记忆，默认启用）、`#todo`（待办，未在删除范围内）
    与 `#userfilerecord` / `#eventlog` / `calc` / `data` 示例。
  - **源码文件**：删除仓库内实际存在的 `MCP/weather.py`。
    （`MCP/emoji.py`、`MCP/get_location.py`、`MCP/topic_interest.py`、
    `MCP/todo_list.py`、`MCP/movieinfo-get-office.py`、`MCP/bilibilisearch/`、`TTS/`
    在源码仓库中本就不存在，仅部署目录里有，无需处理。）
  - **系统提示词**：
    - `prompt_extra.txt` 与 `prompts/default/prompt_extra.txt`：删除
      「系统提供了哔哩哔哩视频功能…」与「如果要发表情，你要先调用表情列表工具获取路径…」
      两句，仅保留媒体发送规则（发纯文字不要调 send 工具）。
    - `prompt_extra_2.txt`：删除 `emoji-list_emojis` 相关表述
      （第 6 行改为「…from the media tools」，删除第 7 行 emoji 发送说明）。
  - **依赖**：`requirements.txt` 删除 `bilibili-api-python==17.4.2`（仅 bili 工具需要）。
  - **文档**：`README.md` / `README_EN.md` 简介与「MCP 工具源」功能项删除
    天气 / 定位 / B站 / 话题兴趣 的表述（保留项目自身的 B站演示视频链接）。
  - **其它引用**：`botapp/robot.py` 的 `/清除记忆` 提示文案去掉「话题兴趣」；
    `_handle_auto_send` docstring 去掉「（如 tts）」举例；
    `.dockerignore` 删除 `TTS` 条目；`.gitignore` 删除 `bili_credential*` 条目。
- **验证**：
  - `configparser` 解析 `config.ini` 通过，`[mcpsources]` 仅剩 `ombre` 生效项。
  - 全仓库扫描确认已无 `movieinfo / get_location / topic_interest / bilibilisearch /
    tts_mcp / emoji.py / weather.py / 哔哩哔哩 / bilibili-api / emoji-list_emojis`
    等残留引用（`config.ini` 中保留的 `#todo` 属未删除项，符合预期）。
  - `MCP/` 目录只剩 `OB/`、`event_logger.py`、`userfile.py`。
- **备份**：改动前备份至 `_backup_mcpsources_<时间戳>/`。
- **备注**：只修改源码版本（`OpenCompanion-main`），未触碰部署版本（`OpenCompanion`）。
