# 版本修复记录（notes）

本目录按**版本**归档每个版本修复的功能与缺陷，方便回溯"哪一版改了什么"。

## 目录约定

```
notes/
├── README.md          # 本文件：说明与索引
├── v1.0.4.md          # 某一版本的修复清单
├── v1.0.5.md
├── v1.0.6.md
├── v1.0.7.md
├── v1.0.8.md
├── v1.0.9.md
├── v1.0.10.md
├── v1.0.11.md
└── ...
```

## 命名规则

- 文件名 = 版本号，如 `v1.0.4.md`（与根目录 `new_adds.md` 的版本号保持一致）。
- 每个版本一个文件；同一版本内的多次修复追加到同一文件，按时间倒序排列。

## 单版本文件模板

```markdown
# vX.Y.Z 修复记录

## 修复项标题
- **现象**：用户/测试看到的问题。
- **根因**：定位到的具体代码位置与原因。
- **修复**：改了哪些文件、怎么改。
- **验证**：如何确认修复生效。
- **关联文档**：详细说明见 `docs/xxx.md`（如有）。
```
