# v1.0.5 修复记录

> 本文件记录 v1.0.5 版本修复的功能与缺陷，按时间倒序排列。

---

## 后端静态网页迁移到 Vue 3 技术栈（功能不变）

- **需求**：后端网页控制台由手写 vanilla JS 改为 **Vite + Vue 3 (SFC)** 技术栈，
  **功能与外观保持不变**，改造前已备份。
- **现状**：原前端为 `botapp/webconsole/static/` 下的原生 ES Module
  （`app.js` + `pages/*.js` + `index.html` + `style.css`），hash 路由 + SSE。
- **改动**：
  - 新增前端工程 `botapp/webconsole/webui/`（Vite + Vue 3 + vue-router）。
  - `vite.config.js` 把构建产物直接输出到 `../static/`，**后端 `server.py` 未改动**。
  - 复用旧 `style.css` 与 logo，保持外观一致；沿用相同 DOM class 名。
  - 11 个页面全部用 SFC 重写：Overview / Console / Accounts / Chat / Debug /
    Memory / Config / Prompts / Stats / Data / Feedback。
  - 公共逻辑抽到 `src/lib/`：`api.js`（API+格式化）、`state.js`（全局状态）、
    `logs.js`（SSE 日志流 + 订阅）、`toast.js`、`authBus.js`（401 跳登录）。
  - `LogView.vue` 复用为概览页与日志控制台的实时日志组件。
  - 路由保持 **hash 模式**（`#/overview`），与旧版行为一致，服务端无需 catch-all。
- **备份**：改造前的原始前端与后端备份于
  `_backup_webconsole_<时间戳>/`（源码仓库根目录）。
- **验证**：
  - `npm run build` 构建成功（46 模块，产物 `static/index.html` + `static/assets/*`）。
  - 端到端冒烟（启动 `WebConsoleServer`）：`/` 200、`assets/*.js` 200、
    `assets/*.css` 200、`logo-square.png` 200、`/api/auth/status` 200。
- **关联文档**：`botapp/webconsole/webui/README.md`
- **修复（配置页无法展示）**：`read_yaml()` 不返回 `descs`/`combo`（仅 `read_ini()` 返回），
  而 Config.vue 模板直接访问 `yaml.data.descs[sec]` → 渲染期报错、整页空白。
  已把 `descs`/`combo` 提为组件本地字段并默认 `{}`，模板改用 `yaml.descs`/`yaml.combo`。
  经无头浏览器（注入 EventSource 桩避免 SSE 挂起）逐路由验证：
  配置页及其余 11 个页面全部正常渲染。
- **备注**：`botapp/webconsole/webui/node_modules/` 已加入 `.gitignore`。
