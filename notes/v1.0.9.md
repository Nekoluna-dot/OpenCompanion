## 网页控制台 UI 清理：去除装饰性符号 / 废话文案 / AI 味注释

- **现象**：控制台界面里到处是装饰性符号（导航图标 `◉ ▤ ◎ ✉ ◇ ◈ ⚙ ◑ ▥ □ ✎`、
  状态里的 `● / ○`、调试页的 `⏳ ⊘ ⊝`、聊天页事件前缀 `→ ← ⚙ ◆ ⬡ ⊕ ⏱ ◈ ✓ ✗`、
  反馈单的 `▾`），文案偏啰嗦（`清空日志窗口`、`输入登录密码以继续`、`集成`、
  页脚 `© 2026 ... 保留所有权利` 重复三次、各处 `…` 提示），
  且**每个源文件开头都有一大段"XX 页 · Animal Island 风格"的注释横幅**，
  代码里还散落"（对应原 app.js 的 xxx）"这类迁移遗留注释，整体很像 AI 生成的项目。
- **根因**：v1.0.5 从 vanilla JS 迁移到 Vue 时，把旧版的图标字体、装饰字符和
  旧注释一并照搬，没有做减法。
- **修复**（`botapp/webconsole/webui/src/`）：
  - **导航**：`router.js` 的 `NAV` 去掉 `icon` 字段；`App.vue` 去掉
    `<span class="icon">` 标记，改为纯文字按钮；`theme.css` 删除
    `.nav button .icon` 规则。
  - **顶栏 / 状态**：`● 机器人运行中 / ○ 机器人未运行` → `机器人运行中 / 机器人未运行`；
    删除面包屑 `控制台 / XX`（`crumb` computed 与 `.page-crumb` 样式一并移除）。
  - **调试页**：去掉 `waitIcon` 状态与 `⏳ / ⊘ / ⊝` 三个符号，等待提示只保留文字。
  - **聊天页**：`EVENT_STYLE` 去掉 `icon` 字段，事件标签只显示文字；
    折叠箭头 `▼ / ▶` 改为 `收起 / 展开`。
  - **反馈页**：`▾` 三角改为纯 CSS 三角（`theme.css` 的 `.fb-chev` 用 border 绘制），
    避免依赖字符字形。
  - **Overview / Memory**：全角空格 `　`、`→` 换成 `·`，读起来更干净。
  - **废话文案**：删除 `清空日志窗口` → `清空日志`、`输入登录密码以继续`、
    快捷入口的 `集成` 一行、页脚版权行（三处，只留 GitHub 链接）、
    `我的反馈` 空态的说明副标题、`暂无登录二维码` 等冗余提示语。
  - **注释**：删除所有 `.vue` / `.js` 文件开头的 2~3 行横幅注释；
    删除 `（对应原 app.js 的 xxx）`、`（与旧版保持一致）` 等迁移遗留注释；
    `theme.css` 文件头的 5 行说明块删除；仅保留必要的功能性注释
    （如 `Config.vue` 的 model 字段说明、`Prompts.vue` 的静默失败说明）。
- **验证**：
  - `npm run build` 通过（47 modules）。
  - 全量扫描确认前端源码中已无 Dingbat / 几何符号（`U+2190`~`U+2B21`、`U+25A0`~`U+27BF`、
    emoji 区），仅剩中文标点级字符（`…`、`—`、`·`）。
  - 无头 Edge 逐路由冒烟：11 个路由（overview / console / accounts / chat / debug /
    memory / config / prompts / stats / data / feedback）全部正常挂载渲染。
- **备份**：改动前整目录备份至 `_backup_webui_uiclean_pre_<时间戳>/`（不含 `node_modules`）。
- **备注**：只动前端源码与构建产物 `botapp/webconsole/static/`，后端 API 未改动。

## 聊天测试页用户 ID 无法下拉选择（v1.0.5 迁移时丢失）

- **现象**：`/#/chat` 页的「用户 ID」和「历史记录」只有纯文本框，
  无法像旧版那样下拉选择已有用户，只能手打完整 ID。
- **根因**：v1.0.5 从 vanilla JS 迁移到 Vue 时**漏掉了旧版的 `<datalist>`**。
  旧版 `static/pages/chat.js` 里是：
  ```html
  <input id="ch-user" list="ch-users">
  <datalist id="ch-users"></datalist>
  ```
  并用 `refreshOptions()` 把 `/api/users` 返回的用户列表填进 datalist；
  新版 `Chat.vue` 只剩一个 `<Input>`，`allUsers` 虽然仍在拉取并保存，
  但**没有任何 UI 用到它**，等于白取。
- **修复**（`botapp/webconsole/webui/src/pages/Chat.vue`）：
  - 「用户 ID」行与「历史记录」行各加一个 `animal-island-ui-vue` 的
    `<Select>`，`options` 来自 `allUsers`（`/api/users` + localStorage 缓存）。
  - 保留原有 `<Input>` 作为「或手动输入」的兜底，两者双向同步
    （`userSelectValue` / `histSelectValue` 两个 computed 代理）。
  - 选择用户后自动触发 `renderHistory()` / `loadHistory()`。
- **验证**：无头 Edge 打开 `#/chat` 并自动展开下拉，
  确认渲染出 2 个 combobox、3 个 option（与 mock 的 `/api/users` 一致）；
  点击第二个选项后，输入框与下拉标签都同步为
  `o9cq80zf3chwTUyjQDD-77pyWzwo@im.wechat`。
- **备注**：`animal-island-ui-vue` 的 `Select` **没有 `filterable`**（该版只支持
  `modelValue / options / placeholder / disabled`），所以没做输入过滤，
  用「下拉 + 手动输入框」双控件组合覆盖两种场景。
